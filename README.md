Tutorial:

	1- Clonar o projeto do GitHub
	2- Abrir um interpretador de linha de comando [no windows cmd]
	3- Navegar até a pasta do projeto
	4- Executar o comando: [docker compose up -d --build]
	5- Abrir o navegador e utilizar a seguinte url [webapp: http://localhost:8080 || api http://localhost:5000]
